🚀 簡易模式 (已預設 UA)

本版本已為您預設好 User-Agent。若網站無特殊加密，您只需填寫 「3. 字幕內容」 即可一鍵下載。

🎯 如何找到正確的 Request URL ?

1

點擊 Network 列表中的字幕檔 (那個內容有一堆 .vtt 的檔案)。

2

看右側面板的上方分頁，點擊 [Headers]。

3

找到 Request URL。複製該連結（如果是相對路徑時，這步必填）。

📄 如何找到字幕內容 ?

1

在 Network 搜尋 m3u8 或 vtt。

2

找到 Response 裡有一堆 .vtt 檔名的檔案。

3

複製該內容貼到左側的「3. 字幕內容」後點擊下載。

🛠️ 關於 User-Agent 的作用 User-Agent 是告訴網站「你是誰」。某些網站 (如 Hotmart) 會檢查這個指紋來防止非瀏覽器的下載行為。本工具已預設為主流 Chrome 指紋以提升成功率。
